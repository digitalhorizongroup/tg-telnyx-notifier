# TG Telnyx Notifier

## Язык общения — русский

Всё, что читает человек, пишется по-русски: финальный ответ, уточняющий вопрос,
варианты в нём, план, заголовок задачи, сообщение коммита. Английский остаётся
там, где он часть кода: имена, литералы, `description` полей схем, обращённые к
модели, — и в цитатах вывода инструментов.

Правило про язык, а не про перевод: ответ не переводится с английского, а сразу
пишется по-русски. Термин, у которого нет принятого русского имени (`prefix-кэш`,
`long-poll`, `workspace`), остаётся как есть — калька ради самой кальки хуже
заимствования.

## Справочные источники (llms.txt)

Перед ответом подгружай актуальную документацию через `WebFetch` — не отвечай по памяти.

### Настройка Claude Code

Когда я прошу настроить тебя самого — hooks, slash-команды, subagents, skills,
MCP-серверы, `settings.json`, permissions, `CLAUDE.md`, IDE-интеграции, keybindings —
сначала загрузи:

    https://code.claude.com/docs/llms.txt

Это индекс документации: возьми из него ссылку на нужный раздел и дочитай его,
прежде чем менять конфигурацию.

### Telnyx

Когда работаю с Telnyx — отправка SMS/MMS, голосовые вызовы, номера, webhooks,
подписи вебхуков, ключи API, лимиты и коды ошибок — сначала загрузи:

    https://developers.telnyx.com/llms.txt

Индекс разбит по продуктовым разделам: у каждого свой краткий указатель со
списком эндпоинтов и парный `-full.txt` с полным текстом страниц. Бери узкий
раздел, а не весь корпус.

### Pydantic / PydanticAI

Оба сайта переехали на `pydantic.dev` (301, смена хоста). Старые адреса рабочие,
но каждый стоит одного лишнего редиректа — ходи сразу на канонические.

**PydanticAI** — агенты, тулзы, toolsets, зависимости, провайдеры моделей,
структурированные результаты, evals:

    https://pydantic.dev/docs/ai/llms.txt

**Pydantic** — модели, валидаторы, `Field`, `model_config`, сериализация,
`TypeAdapter`, `pydantic-settings`, миграция v1 → v2:

    https://pydantic.dev/docs/validation/llms.txt

Для кода агентов обычно нужны оба: API самого агента — из первого, схемы
входов/выходов — из второго.
