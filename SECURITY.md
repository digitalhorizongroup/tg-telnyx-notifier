# Политика безопасности

Не публикуйте уязвимость, токены, webhook-секреты, номера или содержимое сообщений в GitHub Issues.
Откройте [закрытый отчёт](https://github.com/digitalhorizongroup/tg-telnyx-notifier/security/advisories/new).

Укажите затронутую версию, шаги воспроизведения, влияние и минимальный пример без реальных
секретов и персональных данных. Исправления безопасности выпускаются для актуальной ветки `main`.
